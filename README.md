# Холст AI-Оператора + бонуси після ефіру

Прод: **https://ai-operator-holst.vercel.app** (Vercel, проєкт `ai-operator-holst`).

| Адреса | Що це |
|---|---|
| `/` | «Все ваши бонусы после эфира»: дві картки, холст і AI-барига. Це посилання менеджери надсилають після вебінару. |
| `/holst` | Холст: 7 послуг з прикладами, охотник, «Формула заработка», пакети Bronze / Silver / Gold. |

## Структура

```
build.py      збирає site/index.html (бонуси) і site/holst.html (холст), пише site/vercel.json
holst.css     стилі холсту           holst.js   анімація охотника, калькулятор, навігація
hub.css       стилі сторінки бонусів
prep.py       готує медіа в site/media з gen/ і holst-src/ (потрібен лише для нових картинок)
gen/          вихідники згенерованих картинок
holst-src/    початковий холст Влада (референс)
site/         готовий сайт, саме ця папка деплоїться
docs/         ТЗ синку 18.11 (AUDIT і CHANGES за 01.10 лежать у корені)
_shots.mjs    скріни через headless Chrome
```

## Як зібрати і викласти

```bash
python3 build.py
```

```bash
cd site && vercel deploy --prod --yes
```

ZIP для передачі (HTML + усі файли, працює з диска): `python3 _zip.py` → `dist/ai-operator-holst-site.zip`.

Перевірити локально: `python3 -m http.server 8781`, потім відкрити `http://127.0.0.1:8781/site/` і `.../site/holst.html`.

## Що міняти найчастіше (константи в build.py)

- `HUNTER_LEFT` — скільки місць на AI-охотника залишилось із 20.
- `PAKETY` — пакети й ціни (перекреслена й нова).

## Правила

- Охотника не продають і не роздають. На сторінках не має бути посилань на ai-hunter чи демо охотника, тільки «в подарок первым 20 купившим».
- Оплату приймають менеджери, тому посилань на оплату на сторінках немає.
- Агента, який робить сайти, після вебінару не дають: він платний і входить у програму (Софія, 24.11).
